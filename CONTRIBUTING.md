# Contributing to AnatoAR

Thank you for your interest in AnatoAR.

## Before contributing

- Read `README.md`, `AGENT_GUIDE.md`, and the relevant feature specification.
- Keep contributions focused and reviewable.
- Do not submit assets unless their source and license are documented.
- Do not add personal-data collection, AI inference, authentication, or backend learner records to the BYOP scope.

## Development workflow

1. Open or identify an issue describing the work.
2. Discuss substantial design changes before implementation.
3. Make a focused change.
4. Add or update tests.
5. Run lint, type-check, tests, and build scripts available in the repository.
6. Update documentation when behavior or architecture changes.
7. Describe what was tested and what remains unverified.

## Content contributions

Anatomy content should include reputable references and should be reviewed before being treated as authoritative. Clearly mark draft content.

## Asset contributions

Include the asset source, creator, license, attribution requirements, and any modifications. Contributions with unclear reuse rights cannot be accepted.

## Reporting issues

When reporting an issue, include:
- browser and device
- steps to reproduce
- expected behavior
- actual behavior
- relevant console errors, with secrets and personal information removed
